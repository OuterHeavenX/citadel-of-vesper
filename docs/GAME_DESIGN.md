# GAME DESIGN — The Citadel of Vesper

> Living design document. Wave 0 locks pillars and the vertical slice;
> later waves fill systems in.

## Pillars

1. **Movement feel first.** Responsive, heavy, never floaty (tuning.js).
2. **Curiosity is the quest log.** Every room hints at something beyond it.
3. **Equipment changes play, not just numbers.** Weapon families, specials,
   accessory combos (spec §21).
4. **Secrets respect the player.** Environmental tells, never pixel hunts.
5. **The Citadel remembers.** Two Ages of Vesper (Living / Ruined) — the
   late-game revelation that recontextualizes the whole map (spec §49).
   NOT an inverted castle; time, not reflection.

## Fantasy

Lucien Vale, disgraced scion of an ancient order, enters a fortress-city
that appeared during a celestial event — a place his bloodline is tied to.
He is powerful but vulnerable; the Citadel is always older than he is.

## Vertical slice (Wave 1–5): Moonlit Gate → Hollow Keep

15–25 rooms. Title → New Game → opening → movement → combat → breakables →
currency → weapon find → equip → XP/level → hidden passage → map → save
room → save → miniboss (Chapel Warden) → traversal ability (Moonrise Leap)
→ backtrack → secret → Hollow Keep → major boss (Sable Matriarch) → save →
quit → Continue resumes. (Full loop: master prompt §52.)
