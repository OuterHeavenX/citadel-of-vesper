# BOSSES — The Citadel of Vesper

> Memorable original bosses. Never recreate Castlevania bosses, names, or
> patterns.

## Boss contract (spec §36)

Each boss: unique silhouette, custom arena, entrance sequence (camera lock
+ name banner), multiple telegraphed attacks, phase changes at HP
thresholds, death animation, reward. Data: `data/bosses.json`.

## Vertical slice

### Chapel Warden (miniboss) — Moonlit Gate arena
- "Warden of the Gate Chapel". Hollow ceremonial armor guarding a chapel
  whose dead are gone.
- 2 phases (bell toll adds at 50%). Reward: **Moonrise Leap** (traversal
  ability) + XP. Unlocks backtracking.

### Sable Matriarch (major boss) — Hollow Keep arena
- "Matriarch of the Hollow Keep". Ruled in the Living Citadel; never left.
- 3 phases (lantern call, throne quake). Reward: Moonsteel Sabre + XP.
